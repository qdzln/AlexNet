# 第五阶段实验计划

本实验测量手写 AlexNet 在 Fashion-MNIST 上的分类准确率，并观察 BN、Dropout、SGD 动量和用自注意力替换部分全连接层后的表现。测试目标为完整 10,000 张中正确数超过 9,000。

| 问题 | 比较 | 主要证据 |
| --- | --- | --- |
| BN 如何影响性能 | Adam 基线与仅开启卷积 BN | 验证曲线、最佳轮次和各集合准确率 |
| Dropout 如何影响训练与泛化 | Adam 基线与两个隐藏层使用 Dropout=0.5 | 固定最佳权重的训练及测试准确率 |
| SGD 动量如何影响优化 | 同一学习率下比较动量 0 与 0.9；每组单独按验证集选学习率 | 两个匹配学习率的差值、验证曲线与损失 |
| 自注意力分类头是否适合本任务 | Adam 基线与自注意力分类头 | 准确率、参数量、单轮耗时 |

全部 5 轮对照使用相同的 54,000／6,000 分层划分、批次大小 64、划分种子 42 与训练种子 42。预处理固定，学习率不随轮次改变，无数据增强。每组按验证准确率最高选检查点，同分时取验证损失较低者。沿用第四阶段已归档的 Adam 基线。模型使用同一个随机种子，结构改变后随机参数的对应关系会变化。单次运行的差异只描述本次设置，不能估计跨种子波动或统计显著性。

| 组 | 固定配置或网格 |
| --- | --- |
| 基线 | Adam，学习率 0.0003，BN 关闭，Dropout=0，线性分类头 |
| BN | 基线打开 BN，卷积在 BN 前省略偏置 |
| Dropout | 基线设置 Dropout=0.5 |
| Attention | 基线替换分类头，从 2×2 特征图构造四个空间 token |
| SGD | 学习率 0.01、0.03，动量 0 |
| SGD + momentum | 学习率 0.01、0.03，动量 0.9 |

执行顺序为现有基线核验、5 轮对照、12 轮候选训练、封存选模记录、统一测试、整理结果。SGD 网格用验证集各自选优并同时保留两条匹配速率的对照。5 轮各组训练结束后，按验证准确率高、验证损失低、实验名排序选择配置，把该配置原样延长到 12 轮并从头训练。最终候选在所有已完成运行中按同样的验证排序确定。术语“最佳”始终指这一规则。延长训练的结果单列，避免与 5 轮对照混用。

封存选模记录后统一评估已完成各组的最佳权重。每次都覆盖完整测试集并记录正确数、检查点哈希。报告按封存的候选给出最终成绩。失败运行保留配置、状态和已写出的历史。

预计 7 组新对照加 1 组延长训练共 47 个 epoch。按第四阶段 RTX 3050 Ti 每轮约 20 秒估计，GPU 用时约 16 分钟，外加验证集重评、测试与文件保存。实际用时取各运行日志。多种子复验可用于后续检验结果是否稳定。
